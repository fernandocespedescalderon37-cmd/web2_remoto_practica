# Catálogo Tech - TechStore Univalle

## Descripción
Aplicación web interactiva de catálogo de periféricos y componentes tecnológicos con filtrado dinámico por categorías, desarrollada para la asignatura de Programación Web II en la Universidad del Valle.

## Tecnologías Utilizadas
* **HTML5:** Estructura semántica del catálogo.
* **CSS3:** Diseño visual, estilos responsivos y maquetación en cuadrícula (Grid).
* **JavaScript:** Lógica de renderizado y filtrado dinámico de productos.
